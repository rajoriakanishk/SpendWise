SpendWise Student Panel — updated prototype

Files
- index.html: student panel markup and modal forms
- css/style.css: application theme and responsive styles
- js/app.js: navigation, expenses, savings-goal CRUD, add-savings dialog, and profile picture interactions

Run locally
1. Extract the ZIP.
2. Keep the folder structure intact.
3. Open index.html in a modern browser. For best results, serve the folder using a local static server (for example, VS Code Live Server).

Notes
- This remains a front-end demo with sample expenses and goals; there is no backend/account sync.
- Savings goals are kept in page memory for this demo session.
- The profile picture is saved in this browser's localStorage when available, so it remains on the same browser/device.
